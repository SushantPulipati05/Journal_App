Decisions to check

Paper, not white. The page is a warm cream; cards are a lighter sheet on top, so they lift off the page without heavy shadows.
Ink, not black. Text is a sepia-black, softer than #000 but still 10–14:1 contrast for long reading.
Same purple, deeper. The dark theme's lavender would be too faint on paper, so the accent is a deeper violet of the same hue.
Setting: Settings → Appearance → System / Paper / Dark. “System” follows the phone's light/dark mode.
